## GitHub Copilotの最新機能（2026年版）

### Agentic Memory（エージェント記憶）

Copilotがプロジェクトについて学習した内容を記憶し、次回以降の作業に活用する。

**できること:**

- コードベースの構造を記憶
- プロジェクト固有の命名規則を学習
- 過去の会話履歴から最適な提案

**使い方:**

```
// 最初に「このプロジェクトではRepositoryパターンを使っている」と伝える
// → 次回以降、自動的にRepositoryパターンでコードを生成
```

### Custom Instructions（カスタム指示）

プロジェクト固有のルールをCopilotに覚えさせることができる。

**設定例:**

```markdown
---
applyTo: '**/*.ts'
---

# コーディング規約

- アロー関数を使用
- constを優先、letは最小限
- 必ずTypeScript型定義を付ける
- 変数名は descriptive に
- データアクセスはRepositoryパターン
```

これを設定すると、すべてのTypeScriptファイルで自動的にこのルールに従ったコードが生成されます。

### MCP Servers（Model Context Protocol）

外部ツールやAPIをCopilotに接続して、機能を拡張できる。

**できること:**

- データベースへの直接クエリ
- 外部APIの呼び出し
- ファイルシステムの操作
- カスタムツールの統合

**例:**

```bash
# PostgreSQLデータベースに接続
gh copilot mcp install postgresql-server
# → Copilot Chatから「データベースのユーザーテーブルを見せて」でクエリ実行可能
```

### Copilot CLI（強化版）

コマンドラインで自然言語を使ってコマンドを実行できる。

**使い方:**

```bash
# インストール
gh extension install github/gh-copilot

# 使用例
gh copilot suggest "現在のディレクトリで最も大きいファイルトップ5を表示"
# → 適切なコマンドを提案（du -ah . | sort -rh | head -5）

gh copilot explain "docker compose up -d"
# → コマンドの詳細な説明
```

:::tip
2026年1月から、GitHub CLIに統合。`gh copilot`で直接使える。
:::

   - 1分の音声サンプルをアップロード
   - その声で任意のテキストを読み上げ
   - 自分の声でオーディオブックを作成可能

3. **Dubbing（吹き替え）**
   - 動画をアップロード
   - 他言語に自動翻訳＆吹き替え
   - 元の声のトーンを保持

4. **Sound Effects（効果音生成）**
   - テキストから効果音を生成
   - 「ドアが閉まる音」「雨の音」など

**料金プラン:**

- Free: 月10,000文字（約30分の音声）
- Starter: $5/月（30,000文字）
- Creator: $22/月（100,000文字）
- Pro: $99/月（500,000文字）

**実際の使用例:**

- YouTube動画のナレーション
- オーディオブック制作
- eラーニングコンテンツ
- ポッドキャスト
- ゲームのキャラクターボイス
- 多言語対応の動画コンテンツ

:::tip プロの品質
プロの声優レベルの品質。実際に多くのYouTuber、ポッドキャスターが使用しています。
