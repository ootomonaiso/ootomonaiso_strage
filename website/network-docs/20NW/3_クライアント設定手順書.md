# 3. クライアントPCの設定手順書

## 3.1 ネットワークの設定

### o-client（大阪事業所）のネットワーク設定

1. **ネットワーク設定を開く**
   - スタートメニュー → 設定 → ネットワークとインターネット
   - イーサネット → アダプターのオプションを変更する

2. **DHCPによる自動取得設定**
   - イーサネットアダプタを右クリック → プロパティ
   - インターネットプロトコルバージョン4(TCP/IPv4)を選択 → プロパティ
   - 「IPアドレスを自動的に取得する」を選択
   - 「DNSサーバーのアドレスを自動的に取得する」を選択
   - OK → OK

3. **取得確認**
   - コマンドプロンプトを開く

   ```cmd
   ipconfig /all
   ```

   - IPv4アドレス: 192.168.2.201～210のいずれか
   - サブネットマスク: 255.255.255.0
   - デフォルトゲートウェイ: 192.168.1.254
   - DNSサーバー: 192.168.1.1

4. **DHCPが機能しない場合の手動設定**
   - IPアドレス: 192.168.2.201
   - サブネットマスク: 255.255.255.0
   - デフォルトゲートウェイ: 192.168.1.254
   - 優先DNSサーバー: 192.168.1.1

## 3.2 証明書のインストール（t-client）

### ルート証明書のダウンロードとインストール

1. **証明書のダウンロード**
   - Microsoft Edgeを起動
   - http://www.itnetsys.org/CA/ にアクセス
   - cacert.crtをダウンロード

2. **証明書のインストール**
   - ダウンロードしたcacert.crtをダブルクリック
   - 「証明書のインストール」をクリック
   - 保存場所: 「ローカルコンピューター」を選択 → 次へ
   - 「証明書をすべて次のストアに配置する」を選択
   - 「参照」をクリック → 「信頼されたルート証明機関」を選択 → OK
   - 次へ → 完了
   - セキュリティ警告が表示されたら「はい」をクリック

3. **証明書インストール確認**
   - スタートメニュー → 「証明書の管理」で検索
   - 「コンピューター証明書の管理」を開く
   - 信頼されたルート証明機関 → 証明書
   - インストールした証明書が表示されることを確認

## 3.3 Webブラウザ

### 3.3.1 t-client - HTTPSサイトの表示確認

1. **Microsoft Edgeを起動**

2. **HTTPSサイトへアクセス**
   - https://secret.itnetsys.org/ にアクセス
   - 証明書エラーなしでページが表示されることを確認

3. **動作確認**
   - アドレスバーの鍵マークをクリック
   - 接続がセキュアであることを確認

---

### 3.3.2 o-client - Proxyサーバの設定

1. **Proxy設定**
   - スタートメニュー → 設定 → ネットワークとインターネット
   - プロキシ → 手動プロキシセットアップ
   - 「プロキシサーバーを使う」をオンにする
   - アドレス: 10.200.0.2
   - ポート: 8080
   - 「次で始まるアドレス以外にプロキシサーバーを使用する」に以下を入力:
     ```
     localhost;127.0.0.1;192.168.*;10.*
     ```
   - 保存

2. **動作確認**
   - Microsoft Edgeを起動
   - http://www.itnetsys.org/ にアクセス
   - ページが正常に表示されることを確認

3. **ブロック確認**
   - http://www.game.org/ にアクセス
   - アクセスがブロックされることを確認

2. **Thunderbird起動**
   - インストール完了後、Thunderbirdを起動

3. **受信サーバー設定**

   - サーバーのホスト名: mail.tokyo-skills.jp
   - ポート番号: 110
   - 接続の保護: なし
   - 認証方式: 通常のパスワード認証
   - ユーザー名: alice

4. **送信サーバー設定**
   - プロトコル: SMTP
   - サーバーのホスト名: mail.tokyo-skills.jp
   - ポート番号: 25
   - 接続の保護: なし
   - 認証方式: 認証なし
   - ユーザー名: (空欄)

5. **完了**
   - 「完了」をクリック
   - セキュリティ例外の承認が求められたら「セキュリティ例外を承認」

## 3.5 ネットワークドライブ（o-client）

### ネットワークドライブの割り当て

1. **エクスプローラーを開く**
   - Windows + E

2. **ネットワークドライブの割り当て**
   - リボンメニューから「ネットワークドライブの割り当て」をクリック
   - または、PC → 右クリック → ネットワークドライブの割り当て

3. **設定**
   - ドライブ: Z:
   - フォルダー: \\192.168.1.1\share
   - または: \\osv3.osaka-skills.jp\share
   - 「サインイン時に再接続する」: チェック
   - 「別の資格情報を使用して接続する」: チェック
   - 完了

4. **認証**
   - ユーザー名: taro
   - パスワード: smbPass
   - 「資格情報を記憶する」: チェック
   - OK

5. **動作確認**
   - エクスプローラーでZ:ドライブが表示されることを確認
   - Z:ドライブを開く
   - ファイルの作成・編集・削除が可能であることを確認

## トラブルシューティング

### ネットワーク接続の確認

```cmd
# 基本的な接続確認
ping 192.168.1.254
ping 10.200.0.1

# DNS確認
nslookup www.osaka-skills.jp
nslookup mail.tokyo-skills.jp

# ルート確認
tracert 10.200.0.1
```

### Thunderbirdのトラブルシューティング

- **送信できない場合**
  - SMTPサーバー設定を再確認
  - ファイアウォール設定を確認

- **受信できない場合**
  - POP3サーバー設定を再確認
  - ユーザー名・パスワードを確認

### ネットワークドライブのトラブルシューティング

- **接続できない場合**

  ```cmd
  # Sambaサーバへの疎通確認
  ping 192.168.1.1

  # ネットワーク共有の確認
  net view \\192.168.1.1
  ```

- **認証エラーの場合**
  - ユーザー名がtaroであることを確認
  - パスワードがsmbPassであることを確認
  - osv3でSambaユーザーが正しく設定されているか確認

### Proxyのトラブルシューティング

- **Proxyが動作しない場合**

  ```cmd
  # Proxyサーバへの疎通確認
  ping 10.200.0.2
  telnet 10.200.0.2 8080
  ```

- **ブラウザでProxy設定を確認**
  - Edge → 設定 → システムとパフォーマンス → コンピューターのプロキシ設定を開く
  - 手動プロキシ設定が正しいか確認
