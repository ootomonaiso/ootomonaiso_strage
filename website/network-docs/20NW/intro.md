# このドキュメントを読む前に

このドキュメントは本番の資料に沿った設定をしています

## 注意事項

- GigabitEthernetではなくfastethernetを利用しています。GNS3で利用しているイメージの都合です
- まとめ.mdはAIの力の産物なのでミスがある可能性があります
- 1、2、3の設定はいずれも実環境で確認していますが、設定をメモしつつ記述したために記述漏れが十中八九あります。

## ドキュメント構成

このカテゴリには以下のドキュメントが含まれています：

- **0\_まとめ.md** - 全体の設定手順をまとめたドキュメント
- **事前準備.md** - 採点対象外の環境構築手順
- **1\_ルータ設定手順書.md** - R-Tky、R-Kgw1、R-Kgw2の設定手順
- **2\_サーバ設定手順書.md** - osv1、osv2、osv3の設定手順
- **3\_クライアント設定手順書.md** - t-client、o-clientの設定手順
